\section*{Data and code availability}

The costing pipeline, pinned raw downloads, configuration and generated
result macros are available in the accompanying GitHub repository
(\url{https://github.com/PolicyEngine/uk-trade-shock-study}, directory
\texttt{analysis\_taa/}); an archived release with a persistent identifier
will accompany publication. All inputs to the first-pass costings are
public (ONS Labour Force Survey redundancy tables, ONS Annual Survey of
Hours and Earnings, gov.uk statutory parameters). The microsimulation
stage additionally requires the licensed Family Resources Survey via the
UK Data Service, which is not redistributed. Institutional facts are
cited to primary sources with retrieval dates in the repository notes.
